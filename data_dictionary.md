# Data Dictionary

## Primary data source: TGA DAEN

**Source:** Database of Adverse Event Notifications (DAEN) — Medicines
**Custodian:** Therapeutic Goods Administration, Australian Government
**URL:** https://aems.tga.gov.au
**License:** Copyright Commonwealth of Australia; attribution required
**Export date:** 25 May 2026

### Raw data (data/raw/)

The DAEN export files (`.xlsx`) are not redistributed due to size and TGA terms. See `data/raw/README.md` for acquisition instructions.

Each raw file contains:

| Variable | Type | Description |
|---|---|---|
| `Case number` | int | Unique report identifier |
| `Report entry date` | date | Date the report was entered into the DAEN |
| `Age (years)` | numeric | Patient age in years (may be missing) |
| `Sex` | string | Patient sex: Female, Male, Not stated, Another term |
| `Medicines reported as being taken` | text | Multi-line field listing each medicine with brand name, active ingredient, and drug role (Suspected / Not suspected / Interaction) |
| `MedDRA reaction terms` | text | Multi-line field listing MedDRA Preferred Terms |

### Processed data (data/processed/)

Generated by scripts 01–04. Parquet files are not committed (too large); regenerate by running the pipeline.

**daen_merged.parquet** — One row per case (output of `01_parse_daen.py`)

| Variable | Type | Description |
|---|---|---|
| `case_number` | int | Unique report identifier |
| `report_date` | datetime | Report entry date |
| `age` | string | Raw age field |
| `sex` | string | Patient sex |
| `medicines` | string | Raw medicines text |
| `reactions` | string | Raw reactions text |
| `_source_file` | string | Source batch file name |

**daen_cases.parquet** — One row per case (output of `02_clean_daen.py`)

| Variable | Type | Description |
|---|---|---|
| `case_number` | int | Unique report identifier |
| `report_date` | datetime | Report entry date |
| `age` | string | Raw age field |
| `sex` | string | Patient sex |
| `age_numeric` | float | Parsed numeric age (NaN if unparseable) |
| `age_group` | category | <18, 18-64, >=65 |

**daen_case_drugs.parquet** — One row per case × drug (output of `02_clean_daen.py`)

| Variable | Type | Description |
|---|---|---|
| `case_number` | int | Report identifier |
| `brand_name` | string | Drug brand name as reported |
| `active_ingredient` | string | Active ingredient (lowercase) |
| `drug_role` | string | Suspected, Not suspected, or Interaction |
| `raw_text` | string | Original medicine text line |
| `product_id` | string | Study product ID (A01–A08, B01–B07) or null if not a study drug |
| `product_set` | string | A (antivenom) or B (tropical) or null |
| `canonical_name` | string | Standardised product name or null |

**daen_case_reactions.parquet** — One row per case × reaction (output of `02_clean_daen.py`)

| Variable | Type | Description |
|---|---|---|
| `case_number` | int | Report identifier |
| `reaction_pt` | string | MedDRA Preferred Term |

**product_dictionary_prespec.csv** — Pre-specified product dictionary (committed; locked before data acquisition)

| Variable | Type | Description |
|---|---|---|
| `product_set` | string | A or B |
| `product_id` | string | A01–A08, B01–B07 |
| `canonical_name` | string | Standardised product name |
| `active_ingredient` | string | Active ingredient(s) |
| `atc_code` | string | ATC classification code |
| `manufacturer` | string | Manufacturer name |
| `species_genus` | string | Target species (antivenoms only) |
| `search_terms` | string | Semicolon-delimited search terms for DAEN matching |
| `indication_context` | string | Primary therapeutic indication |
| `indication_expected_pts` | string | Semicolon-delimited PTs expected from the indication |
| `notes` | string | Product-specific notes |

## Comparator data source: FDA FAERS

**Source:** FDA Adverse Event Reporting System via openFDA API
**URL:** https://api.fda.gov/drug/event.json
**License:** Public domain

**faers_tropical_basket.parquet** — Top 100 reaction PTs per Set B drug from FAERS (output of `05_parse_faers_comparator.py`)

| Variable | Type | Description |
|---|---|---|
| `drug` | string | Drug name |
| `reaction_pt` | string | MedDRA Preferred Term |
| `faers_count` | int | Number of FAERS reports for this drug–PT pair |
| `faers_total_for_drug` | int | Total FAERS reports for this drug |
